# 每日与聊天使用指南

本文介绍 GamePilot 0.15.13 的通用操作方式，不是某个账号或客户端的实机验收记录。纯源码首发缺少游戏模板和部分运行依赖；先完成 [开发与准备指南](getting-started.md) 中适用于所需功能的准备，不将缺资源的构建当成可直接运行的发行包。

## 首次配置

1. 在设备页检测 MuMu 安装并选择管理器实例，为设备绑定对应账号档案。ADB 名称可能是同一实例的别名，不要只凭显示名称猜测账号。
2. 自行完成客户端安装、更新和首次登录。方舟档案中的服务器、登录匹配信息和预期账号身份必须与实际设备一致；密码和验证码由用户处理。
3. 在每日计划中选择游戏、任务开关、顺序和允许的资源参数，保存后再运行。未保存的编辑不代表后台计划已经改变。
4. 需要聊天时，准备独立 DSH runtime，并在模型设置中配置兼容服务地址、模型和密钥。不要把密钥写进聊天、截图或 issue。
5. 最后检查定时、应用自启、模拟器启动和托盘设置。只有自己理解并启用的配置才应参与后续自动运行。

配置记录不能证明设备当前在线或账号身份已经核验；宿主仍会在执行前检查。游戏和图像资源适配不完整时，应保持相关任务关闭。

## 先查询，再明确交办

可以先问：“只查看当前任务记录，不启动任务。”查询展示的是读取时的账本事实，不保证设备当前画面或整套日常均已完成。

交办时明确账号、游戏、任务及资源限制，例如：“只给账号一执行明日方舟登录，核对账号后回到首页就停，其他任务不做。”这里的账号名称需要与自己的配置对应，示例不是对所有客户端的运行保证。

“运行保存的日常”使用已保存计划的适用范围。只选择部分账号、游戏或步骤时，应在当前消息中明确说明，不能把完整保存计划当作筛选后的计划。宿主可能因身份、历史重叠、资源限制或设备占用而拒绝；不要反复发送同一句来绕过拒绝。

模型正文只作说明。只有宿主受理回执代表任务已交办，而受理仍不等于游戏已经完成。

## 看结果与记录

- 当前消息有已交办 Goal 时，正文显示这些目标的实时宿主结果；点击“查看交办任务”进入同一目标详情。
- 模型前置查询的记录放在“历史参考”中。旧请求的 unknown 或失败不会被新目标的成功覆盖，也不应被当成当前目标的结果。
- 没有新目标的普通结果查询继续显示其查询证据。核对日期、游戏日、账号、原任务范围和步骤，而不是只看“成功”字样。
- “对话 / 轨迹”切换可查看公开工具参数、返回和耗时；模型调用结束不表示原生执行结束。
- “已跳过”需结合原因理解。无可领奖励、已经完成或当前任务不可执行具有不同含义，不能统一解释成已经领取。

可以追问：“刚才做了什么，只告诉我结果，不要重新运行。”缺少证据时应保留无法确认，不以查询为由补跑。

## 停止、暂停与续跑

目标卡的停止入口针对对应目标；停止模型请求只取消推理，不会自动替代游戏目标的停止。紧急“停止全部任务”会影响多个任务，使用前留意其范围。

“当前步骤结束后暂停”等待当前步骤到边界后停止后续项。停止请求已发出、正在确认停止和已经停止是不同状态；原生执行器未确认退出时，设备可能继续保持隔离。不要把窗口关闭或收到超时当成已停止证明。

遇到失败先查看任务详情与已有证据。明确要求继续原目标时，宿主仅在已注册恢复条件满足、账号与设备关联可信、剩余步骤可安全区分时续跑。已完成业务不重做，未知提交不重发；最多两次的恢复上限并不保证每个故障都有恢复动作。

验证码、客户端强制更新、身份不符、未识别页面或业务结果未知可能需要人工处理。结束处理可解除不再继续的旧请求对后续任务的维护阻断，但会保留原始失败或 unknown，不能当成完成记录。不要通过改账本或清空历史强行运行。

## 保存偏好与定时

修改每日开关后检查实际保存范围。聊天中的“以后默认……”与“现在执行……”是不同意图；保存偏好本身不代表立即运行。

定时运行使用设备绑定和已保存计划，只有电脑开机、登录相应用户且 App 正在运行时才有机会触发。错过时段的处理仍受当前时段、游戏日和防重复规则约束，不承诺补跑所有错过任务。

关闭窗口可能只是隐藏到托盘。需要结束常驻时使用 App 的退出入口，并核对已有游戏任务是否停止。首次启动自己构建的 App 前，应留意同一用户目录已有的自动化配置。

## 数据与外部工具

配置、聊天、原请求和本地证据保存在当前用户的 `.gamepilot` 中。不要把这个目录放进源码仓库或作为公开问题附件。删除截图不补造原证据，结束旧请求也不改写其业务结果。

本机 CLI / MCP 连接已经运行的同一 App，仍由宿主核验授权、会话和请求归属；见 [本机控制接口](local-control.md)。它们不是第二个游戏执行器，也不是绕过 GUI 校验的入口。

使用范围和许可见 [第三方说明](third-party-notices.md)。游戏版本、页面皮肤和账号状态变化都可能需要重新适配，本项目不承诺完全无人值守。
