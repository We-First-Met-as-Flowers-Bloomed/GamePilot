# GamePilot 每日任务 · 0.16.0

0.16 新计划需要本机结构化确认，聊天提出请求后先检查卡片中的账号和任务范围再确认。方舟临时作业、识别结果展示、安装与验收边界见 [0.16 更新说明](upgrade-0.16.0.md)。下列历史实测仅证明当时版本与现场，不代替本轮升级认证。

已实测的单项聊天交办：“帮账号二登录阴阳师，只领取邮箱附件和花合战奖励，已经领过就检查后跳过。不要跑明日方舟，不做其他任务，不花任何付费货币。”本轮实际领取邮件、核对花合战无可领并返回庭院。追问“刚才领到了什么，只告诉我结果，不要重新运行”可读取对应任务结果。当前结果直接显示在原指令下，之前查询的旧失败记录收在“历史参考”。详见[玩家指令实测](player-command-validation-2026-10-09.md)。

长聊天不再把所有旧工具输出逐轮累积到新指令的模型上下文中；完整聊天与任务记录仍保留，当前目标通过有界事实与查询工具承接。阴阳师已处置的纯登录超时，只有原业务全部明确未开始且关联证据完整时，才允许新授权计划从登录开始；不把旧 unknown 改写成成功，也不意味着未知业务可以直接重跑。

推荐直接聊天：“帮我把账号二今天的明日方舟日常跑完，按已经保存的设置来，不吃药不碎石。阴阳师先不跑。” 或“现在运行两个账号保存的日常”。执行中问“现在做到哪一步了”会查询进度，不重新开始。

更新客户端后，先说“先帮我登录两个明日方舟账号，核对账号，回到首页就停，其他日常先不做”；核验通过后可说“继续账号一刚才没做完的日常，已经完成的别重复”。自动接管原日常只适用于可证明后续业务尚未提交的登录中断；其他未知结果仍需核对。阴阳师礼包出现疑似价格时不会购买，也不会记作已领取。旧历史处置请在每日计划的待核对记录中处理，不要反复重新开始。

本版完善聊天交办、分账号任务、当前目标继续/停止、会话任务区和宿主结果核验，详见 [聊天使用方法](gamepilot-chat-use-0.15.0.md)。原失败重试、暂停和原进度续跑保留；可确认、尚未提交的启动失败最多重试两次，未知结果先核对。重新启用寄养不能跳过未处置记录。

验收由开发负责。本轮通过正常聊天完成两个明日方舟账号六项日常，信用余额均低于300；阴阳师账号一礼包未确认，账号二遇到MuMu崩溃中断。完整双游戏无人干预与七天稳定性尚未通过，见 [本轮实机记录](player-agent-live-2026-10-09.md)。

默认使用聊天工作台。原设备、每日计划、游戏参数、任务开关、模型设置和执行记录在侧栏工具中。两台 MuMu 并行，每台按明日方舟 → 退出方舟 → 阴阳师执行。早 08:00 双游戏，晚 20:00 仅方舟，使用保存的账号和设置。

兼容模型聊天运行官方 DSH 内核。聊天“现在运行两个账号保存的日常”会提出保存范围的请求，本机确认后由原执行器执行。聊天“只预览，不执行”仍只检查计划。顶部“对话 / 轨迹”切换保留输入内容，轨迹可查看脱敏工具参数、返回、耗时与对应游戏回执；历史缺项显示未记录。只跑某账号或跳项在需求中说明，并核对确认卡的实际范围。模型回复结束不代表游戏完成；以目标卡和原请求证据为准。

可以继续问“刚才检查为什么没有通过”。模型会读取本会话对应的原宿主检查回执；检查已受理不代表游戏完成，检查因已有记录拒绝也不代表原日常已经成功。

阴阳师商店保留上次页面时，登录先从已识别的商店返回庭院并重新核验；领取时核对商店导航，再进入礼包屋日常页，仍只领取第一张免费每日礼包。失败后使用“继续未完成任务”，可保留已完成的明日方舟、签到和邮件步骤。未知画面仍需核对，不能视为 Agent 已恢复。

## 配置

1. 在设备页绑定 MuMu 管理器路径、实例与账号档案，只启用实际登录的游戏。MuMu 已停止且管理器返回本机已确认的 900/RPC 停止状态时，可正常发现实例并由执行流程启动；未知错误仍停止。
2. 方舟设置选择官服/B服、预期 UID、代理关卡、公招、邮件与信用购物。UID 从好友个人名片核验；游戏密码和验证码由用户处理。
3. 每日计划调整步骤开关、顺序和星期。阴阳师集体任务、好友寄养不在主要默认日常，原单项与维护功能保留。
4. 模型设置保存兼容 API 地址、模型和密钥，或选择支持的本机 Codex。密钥只在 App 设置输入，不放进聊天或 CLI。
5. 设置中确认 Windows 登录自启、08:00/20:00 和托盘常驻。应用自启与任务到点执行分别设置；不开机或未登录 Windows 时不执行。

## 聊天控制

输入“运行保存的日常”提出保存范围的执行请求，再在本机确认；晚间默认方舟，“运行双游戏日常”提出完整双游戏计划。模型说明、查询和预览不能授予执行权限。已完成、未核对或重叠请求会阻止重复运行，需查看原请求。工具菜单保留原检查 / 确认入口。目标卡可停止目标；失败后聊天“继续目标 goal-…”核对原剩余步骤再续跑，不重做已完成项。

任务结束会在本会话任务区显示宿主生成的真实结果，不额外调用模型编造完成摘要。可聊天“以后账号一只领取明日方舟邮件，保存默认设置”修改受支持的任务开关；身份、资源和路径不会由模型修改。未来偏好不会让现在立即执行。详细能力、限制与验收入口见 [持续游戏 Agent](autonomous-game-agent-0.14.45.md)。

输入“继续任务”或在 ＋ 菜单选“继续原失败请求”。明确选择原请求，默认重试可重试失败项并继续未开始项，保留已完成步骤。可在原请求详情取消本次不需要的剩余项；取消不算整套完成。部分执行需核对确认，原生已提交且未知不能通过确认绕过。

“当前步骤结束后暂停”作用于选中的精确请求，当前步骤结束后停止后续项及下一游戏，排队与实际生效分别显示。`/stop`、“停止全部任务”或停止按钮可紧急停止，包括受理与启动阶段；游戏自身开始的战斗可能继续。

询问“今天两个账号跑得怎么样，不重跑”，模型只读工具查询。北京时间、游戏日、实际次数和原计划覆盖先显示宿主事实。工具过程与长解释折叠，公开回复流、真实工具开始/返回、用量和游戏回执分别表示；模型回复完成不代表游戏成功。

会话归档保留完整原文及来源，分页只读。活跃模型或属于本会话的游戏执行不能归档。历史草稿和摘要不能复用执行授权，预算不足时归档后新建。

## 游戏和故障

方舟：登录/UID核验 → 公招 → 理智代理 → 基建 → 好友与信用购物 → 任务奖励和邮件/活动附带项，按开关执行。身份确认使用自己的个人名片双帧完整 UID；主页仅读到预设 ID 的截断前缀时只作缺失证据，重新只读识别，不认定异号或身份通过。理智药、临期药和源石补充为零，理智不足后继续其他步骤。基建用进驻总览一键换班、收菜与贸易站无人机。购物按保存偏好与余额核验，已经确认购买、仅返回页面失败时续跑不会重购。

阴阳师：庭院事务每日一签、邮件附件、第一张免费每日礼包、地域鬼王、最后领取花合战，保留游戏内已启用事务开关。麒麟仅北京时间周一至周四 06:00–23:00。没有可领奖励或已有今日成绩时跳过，付费与未知动作停止。

寄养是独立维护，按实际倒计时核对太鼓优先、斗鱼次选与同类最高星，已有寄养不重复派遣；失败或未知停止核对，不热循环。满经验育成槽白达摩替换仍需对应实机覆盖。

失败尽量保存本地截图，可在记录中查看/删除；无图明确说明，不补造旧图。Agent 当前用本机 OCR 的已知页面与脱敏记录诊断，不自动发送完整游戏截图。导航须获得原设备租约并核对前后现场。SDK登录、验证码、身份不符或未知画面转人工，不任意泛点 ×、返回或空白。最多两次恢复，仍失败停止。

## 常驻、数据与验证

关闭窗口隐藏到托盘；托盘或设置中退出才关闭常驻。电脑须开机、登录 Windows 且 App 正在运行。错过时段仅补当前允许时段，完成记录阻止重复。方舟游戏日 04:00，含阴阳师组合日程 06:00，每账号和时段独立记录。模拟器关闭行为按各设备设置。

数据保存在用户目录 `.gamepilot`，升级保留账号、日程、原账本与失败。模型密钥由 Windows 加密，截图/日志只本机保存。换发行目录后从新 App 保存启动设置，确保 Windows 自启路径更新。

开发打包通过完整校验后会清理旧发行包，保留最新两版及仍被进程、启动项、快捷方式或定时任务引用的版本。源码、账号和任务记录不在清理范围；发现额外文件、目录链接或引用读取失败时保留原目录并提示。日常使用无需手动清理安装目录。

Windows x64 需要 Microsoft Visual C++ v14 x64 运行库，本机已具备；换电脑重新检测 MuMu/ADB。发行包 `resources/app/scripts/agent/` 中 CLI/MCP 连接运行中的同一个 App，脚本需 Node.js 22.12 或更新版本，详见同目录 CLI与MCP.md。

软件测试和实机验收分别记录。[2026-10-05 的 0.14.42 双账号保存日常](daily-agent-validation-2026-10-05.md)已在正常 App 完整结束；本轮无失败，未触发故障 Agent。真实故障自动恢复和连续七天仍以实际观察为准，不以模型说明或演练代替。
