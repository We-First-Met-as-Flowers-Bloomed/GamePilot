# 阴阳师适配包

技能目录已接入启动、签到、邮件、免费礼包、集体任务、寄养、麒麟、地域鬼王和花合战。ready=true 表示执行器已接入，不代表任意皮肤或当前游戏版本都已通过无人值守验收。

资源采集顺序：MuMu ADB 连接与分辨率 → 登录/庭院 → 签到前后 → 地域鬼王声望、额度、选择、战斗和完成记录。每个技能需要当前客户端截图、成功条件、失败分支和有界重试。不能用猜测的按钮坐标代替资源采集。

资源置于本目录 resources；游戏规则不能放进 apps 或平台协议。游戏名、角色和每日完成状态必须以当前客户端确认。
